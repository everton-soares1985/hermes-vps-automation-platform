# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Replaced the generic conceptual hero with a photorealistic architecture
  mockup designed for both the GitHub portfolio and LinkedIn case studies.

### Planned

- Normalize partial-success and candidate-exhaustion exit codes.
- Add contract tests for every operational wrapper.
- Complete a route-independent autonomous-builder end-to-end fixture.

## [0.2.0] - 2026-09-25

### Added

- Public, sanitized portfolio edition of the VPS automation platform.
- Live infrastructure audit with aggregate 30-day scheduler evidence.
- Portable health watchdogs and daily evidence-report pattern.
- Architecture, operations, security, failure-mode, and decision documentation.
- Autonomous builder V0 controller, skill, smoke fixture, and 15-test suite.
- GitHub Actions validation and GrowthTech publication checks.

### Changed

- Replaced production filesystem paths with explicit deployment variables.
- Converted operational documentation and script output to English.

### Security

- Excluded credentials, cookies, account identifiers, host coordinates,
  production databases, browser profiles, and raw evidence.

## [0.1.0] - 2026-08-10

### Added

- Initial three-role autonomous-builder controller and smoke validation on the
  private VPS.
